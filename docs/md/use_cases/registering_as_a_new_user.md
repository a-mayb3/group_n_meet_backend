## Use case

Signing up as a new user

## Subjects

- Non-signed-in person
- AI approval agent

## Description

This use case is presented when a non-signed-in person wants to sign up and become a new user.
The to-be-registered user can enter the sign up page and submit the necessary user information through a sign up form.
Once the information has been submitted, an AI approval agent, will review the given data, and decide if the user sign-up submission follows a set of rules.
In case said review is accepted, the new-user will be automatically logged-in their new account and will be able to use the service.
