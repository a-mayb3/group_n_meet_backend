## Use case

Signing up to an event

## Subjects

- User

## Description

This use case starts when an user finds an event of its interest and wants to sign up to participate to it.
The user can press a participate button found inside the event page, once said button has been clicked on, the user is signed up to the event and is now part of the list of participants.
Once signed up, the user can also cancel the participation (see [Cancelling participation of an event](./cancelling_participation_of_an_event.md)).
