## Use case

Cancelling participation for an event

## Subjects

- User

## Description

This use case starts when a user that signed up to participate in an event(see [Signing up to an event](./signing_up_to_an_event.md)) wants to cancel their participation.
The user can press a button in the event page that will delete them from the event participation list.
The user is allowed to sign up again to said event.
