## Use case:

Organizing an event

## Subjects

- An eventgroup member
- AI helper agent
- AI approval agent

## Description

This use case stars when an user, in name of an eventgroup who they are a member of, want to publish a new event into the platform.
The user enters the event information into a "event creation form" and submit the new event.
Optionally, the user creating the event can enable inside the form an AI helper to suggest some information fields such as: description, tags, category, etc.
After the user have submitted the new event, the AI agent is fed the event information and under a set of rules to follow, said AI agent will determine wether the submitted event is valid for publishing.
When the AI agent either approves or discards the submitted event, the userteam will receive feedback telling them the verdict on the event approval.
